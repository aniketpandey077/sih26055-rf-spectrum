# SIH26055 — Adaptive RF Spectrum Scanning (Phase 1)

## 1. What this project is

SIH26055 is an **AI-based Adaptive RF Spectrum Scanning and Intelligent
Decision System**. The end goal (across all phases) is a system that can
intelligently decide which part of the radio spectrum to scan next, using
machine learning.

This repository currently contains **Phase 1 only**: the foundational
environment that later phases will build intelligence on top of.

## 2. What Phase 1 does

Phase 1 builds the basic, working skeleton of the system:

- A **Python FastAPI backend** that simulates an RF spectrum: virtual
  frequency bands, virtual signals, virtual noise, and a virtual receiver
  that can "scan" one band at a time.
- A **Next.js frontend** dashboard that shows the simulated spectrum as a
  graph, lists the available bands, and lets you click **SCAN** on a band
  to see a simulated reading.

There is **no machine learning, no database, no authentication, and no
real RF hardware** in Phase 1. Those are explicitly out of scope for this
phase.

## 3. What "simulation" means here

Every number produced by this project — frequencies, signal strengths,
noise levels — is generated by simple math (NumPy) running on the
simulator's own logic. **The laptop is not transmitting or receiving any
actual radio signals.** Think of it as a realistic-looking flight
simulator for RF data: useful for building and testing the rest of the
system, but not connected to real hardware.

The frontend also visually labels every reading as simulated, so it's
never mistaken for a real measurement.

## 5. How to install & run the backend

```bash
cd backend
python -m venv venv

# activate the virtual environment
# macOS/Linux:
source venv/bin/activate
# Windows (PowerShell):
venv\Scripts\Activate.ps1

pip install -r requirements.txt
uvicorn main:app --reload
```

The backend will start at **http://127.0.0.1:8000**.

You can sanity-check it in a browser or with curl:

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/bands
```

## 6. How to install & run the frontend

Open a **second terminal** (leave the backend running in the first one):

```bash
cd frontend
npm install
npm run dev
```

The frontend will start at **http://localhost:3000** (Next.js's default
dev port). Open that URL in your browser.

The frontend already knows where the backend lives via
`frontend/.env.local`:

```
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

If your backend runs on a different port, change that line and restart
`npm run dev`.

## 7. API endpoints

| Method | Endpoint          | Description                                             |
|--------|-------------------|----------------------------------------------------------|
| GET    | `/`               | Basic sanity check — confirms the backend is running     |
| GET    | `/health`         | Returns `{"status": "healthy"}`, used for the status bar |
| GET    | `/bands`          | Returns the list of all simulated frequency bands        |
| GET    | `/spectrum`       | Returns `{frequency, amplitude}` points for the graph    |
| GET    | `/scan/{band_id}` | Simulates scanning one band, returns a reading           |

Example response from `GET /scan/5`:

```json
{
  "band_id": 5,
  "frequency_start": 300.0,
  "frequency_end": 350.0,
  "signal_detected": true,
  "signal_strength": -42,
  "noise_level": -80.13
}
```

## 8. What is NOT implemented yet (future phases)

Deliberately left out of Phase 1, to be added later:

- Machine learning / XGBoost / scikit-learn
- Anomaly detection
- Uncertainty calculation & information gain
- The adaptive decision engine ("what band should we scan next?")
- Reinforcement learning
- A real database (PostgreSQL / Firebase)
- Docker / Kubernetes
- User accounts / authentication
- Real RF hardware or SDR integration
- WebSockets / live streaming updates (Phase 1 uses plain REST requests)

Phase 1's whole job is to create the simulated environment that those
future, smarter components will eventually operate on:

```
Virtual RF Environment → Simulated Signals → Simulated Receiver
        → Scan → Observation → Dashboard
```

## 9. Notes for the demo

- Every card on the dashboard that shows numbers (spectrum graph, scan
  result) is clearly simulated — there's no real antenna or SDR involved.
- The band list and spectrum range are configurable from
  `backend/simulator/spectrum.py` (just change `SPECTRUM_START_MHZ`,
  `SPECTRUM_END_MHZ`, or `NUMBER_OF_BANDS`).
- The virtual signals (frequency, strength, on/off behaviour) live in
  `backend/simulator/signals.py`.
